# Data Dictionary

All records are synthetic and deterministically generated by `scripts/generate_data.py`.

| File | Key fields | Meaning |
| --- | --- | --- |
| Initiative registry | `initiative_id`, `business_unit`, `lifecycle`, `estimated_annual_value` | Portfolio inventory, ownership context, and stage of each AI use case. |
| Control assessments | `initiative_id`, `control_name`, `status`, `evidence_date` | Required governance-control evidence; `Gap` means missing or failed evidence in this demonstration. |
| Governance exceptions | `exception_id`, `severity`, `age_days`, `status` | Exception operations queue; aging is measured only for open cases. |
| Adoption telemetry | `initiative_id`, `week_start`, `eligible_users`, `active_users`, `workflow_runs` | Weekly adoption activity; it is a usage signal, not a value claim. |
| Value realization | `initiative_id`, `quarter`, `planned_value`, `realized_value`, `confidence` | Finance-style planned-versus-realized value evidence with an uncertainty label. |

## Derived metrics

- **Control coverage:** share of six required controls with `Pass` status per initiative.
- **Governance coverage:** share of initiatives with at least 83% control coverage.
- **Exception aging:** `age_days` among open exceptions; 45 days is an illustrative review threshold.
- **Value realization:** realized value divided by planned value, summed at the requested level.
- **Priority score:** illustrative triage heuristic combining missing control coverage, open-exception count, and maximum age; it is not a production risk model.
